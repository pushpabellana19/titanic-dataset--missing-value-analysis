# Titanic Missing Value Analysis

## Project Overview
This project focuses on identifying and analyzing missing values in the Titanic dataset using Google Sheets.

## Objectives
- Identify missing values in each column.
- Calculate the number of missing values.
- Prepare a missing value summary.
- Understand data quality issues.

## Tools Used
- Google Sheets
- Titanic Dataset

## Key Findings
1. The Age column contains 177 missing values.
2. The Cabin column contains 687 missing values.
3. The Embarked column contains 2 missing values.
4. All other columns have no missing values.
5. Cabin has the highest number of missing values.

## Conclusion
The analysis identified missing values in three columns: Age, Cabin, and Embarked. This analysis helps understand data quality and the importance of handling missing values before performing further data analysis.
